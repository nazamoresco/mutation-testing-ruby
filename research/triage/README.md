# Informes de triage

Cada informe derivado debe mantener el contexto acotado y usar la estructura siguiente:

1. Lote, versión de la sesión y alcance revisado.
2. Patrones agrupados por sujeto o familia de código.
3. Prioridades con evidencia de código y tests relacionados.
4. Hipótesis de categoría, siempre marcada como propuesta hasta revisión humana.
5. Preguntas de dominio y candidatos de validación focalizada.

No incluir el JSON crudo de Mutant, credenciales, bases de datos ni cambios de código de terceros. La consolidación final debe distinguir mutantes vivos de bugs confirmados.
