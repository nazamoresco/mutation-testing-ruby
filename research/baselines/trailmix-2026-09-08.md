- Repositorio: `https://github.com/codecation/trailmix.git`
- SHA: `3565d61e451a39c76ec952acf7e9196c810c5ea6`
- Estado del checkout tras el intento: limpio y detached en el SHA anterior.

## Entorno reproducible

- Host: macOS 26.2 (arm64); Docker Desktop 27.4.0.
- Runner: imagen local efímera basada en `ruby:3.4.2-slim` (aarch64 Linux), con `libpq-dev` y herramientas de compilación.
- Ruby: 3.4.2p28; Bundler 2.6.2; Rails 8.0.5.1.
- Base: PostgreSQL 16 en un contenedor y red Docker exclusivos para este baseline; la base `trailmix_test` se creó con `db:prepare`.
- Configuración: copia de `.env.sample` montada como archivo de solo lectura y valores dummy; no se usaron credenciales reales.
- Bundler: gems en un volumen Docker efímero, fuera del checkout.

## Incidente de compatibilidad del host

El host solo exponía Ruby 2.6.10 como runtime activo y no tenía `mise`. Antes del runner, se intentó compilar Ruby 3.4.2 temporalmente con `asdf`, sin tocar el checkout ni el runtime global. La compilación falló dos veces contra OpenSSL 3.6.0 de Homebrew: `openssl_missing.c` accede a estructuras opacas (`X509_CRL` y `X509_REQ`) y falla con cuatro errores de definición incompleta.

Para no cambiar OpenSSL global ni parchear Trailmix, el baseline continuó en Docker. Esto elimina el bloqueo del host, pero debe conservarse como limitación: las métricas siguientes corresponden al runner Linux, no a una ejecución nativa en macOS.

## Ejecución

- Preparación: `bundle exec rails db:prepare` en la base aislada.
- Primer arranque de RSpec: DatabaseCleaner rechazó inicialmente la URL de la base Docker como remota. Se habilitó `DATABASE_CLEANER_ALLOW_REMOTE_DATABASE_URL=true` exclusivamente para la base efímera; no es una configuración del proyecto.
- Corrida 1: `bundle exec rspec` — código 0; 94 ejemplos, 0 fallas; RSpec 3,66 s; contenedor 7,99 s.
- Corrida 2: `bundle exec rspec` — código 0; 94 ejemplos, 0 fallas; RSpec 3,35 s; contenedor 6,15 s.
- Flakiness observada: ninguna en dos ejecuciones. Los seeds fueron distintos (`53510` y `39373`) y ambos resultados fueron verdes.

El checkout siguió limpio y detached en el SHA fijado. No se modificó ni publicó código del repositorio de origen.

## Decisión

Trailmix queda seleccionado como piloto ejecutable. El siguiente paso es configurar Mutant de forma reversible dentro de este entorno y elegir entre uno y tres sujetos pequeños; no mutar toda la aplicación.
